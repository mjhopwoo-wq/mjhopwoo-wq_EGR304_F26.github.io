## Introduction

This datasheet covers Matthew Hopwood's contribution to team HaMaLoYa's project. The project is a drowsy-driver detection device and the subsystem covered in this datasheet is the board that controls a haptic motor in order to keep drivers awake. 

### Project Summary

The goal of this project is to combine 4 separate subsystems together in order to create a system that accurately detects drowsiness and then acts to wake up drivers. The subsystem in this datasheet will be working to keep the driver awake by providing haptic alerts to the driver. It does this by connecting to the gyroscope board which lets this board know to when the driver is in a drowsy state. The haptic feedback stops when the device detects that the driver is no longer drowsy. Additional information about the system as a whole and the other specific subsystems can be found at the link [here.](https://asu-egr304-2026-f-104.github.io/)
